# Grus boot 2020.7 release notes

## 新特性

### Fegin 支持 Spring MVC 协议

### Swagger 支持

- 
  @NotNull @Length 等 javax 注解会在 swagger 参数上体现；

- 支持了 context-path。

### ExcludePrepareCondition注解

为MQ和Job的bean在预发排除提供优雅方案。

### Grus-Redis 优化

- 
  优化了项目启动时，redis 是否可用的判断；

- 针对 grus-redis 默认的 redis client 添加了 trace（常用 command 命令），同时 tag 添加了执行的 redis 指令，例如：get、set等等，jager 查询问题时，可使用。

### 移除敏感信息

项目中 MQ 的用户名密码，数据库的 public key，frigate 报警请求地址等敏感信息，从代码中移除，移入 gconf。
