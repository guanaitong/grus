# Grus boot 2021.1 release notes

## 不兼容变更

### Swagger

使用 springfox-boot-starter（官方的 starter）替换了原先引入 swagger 的方式。经过封装后，在 grus 中使用方式不变，根据环境（**仅开发和测试才会使用 swagger**）和 grus.swagger.enabled 的值，决定 swagger 是否启用。

swagger 使用 springfox-starter 3.0，入口地址变更：

old：`http://${service-name}/{context-path}/swagger-ui.html`，

now：`http://${service-name}/{context-path}/swagger-ui/`。

针对文件上传的场景，`MultipartFile`类前，需要用 `@RequestPart`标注，不然渲染的`swagger`页面会忽略该文件。

### Health Check

现在框架自己包含了健康检查的 `Controller`，项目中需要移除 `isLive` 的 `@RequestMapping` 或者同样命名的 `Controller`。

健康检查地址为：`http://ip:port/{context-path}/isLive`

```java
@RestController
@RequestMapping
public class GrusHealthCheckController {

    @AppName
    private String appName;

    @LogExclude
    @GetMapping("/isLive")
    public ApiResponse<String> isLive() {
        return ApiResponse.success(String.format("%s is working", appName));
    }
}
```
