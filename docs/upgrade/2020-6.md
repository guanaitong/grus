# Grus boot 2020.6 release notes

## 不兼容变更

### freemarker

freemarker模板的默认后缀变成了.ftlh，大家如果原来使用的ftl，需要增加以下配置：spring.freemarker.suffix=.ftl

### redis

- 规范 redis 使用，移除 RedisConfig。具体见 Redis 模块 


spring-boot-data-redis 中使用 lettuce 作为客户端，目前不支持无限阻塞的方法，会有超时时间的限制，针对 stringRedisTemplate：

- 设置了，如果超时，返回 null；
- 未设置，会立马返回结果；
- 设置为 0，过了默认的超时时间（一般是 60s）会抛异常


针对封装的 RedisService，如果使用 redisService.brpop，如果**超过默认时间，则抛异常**，不再是如以前那样一直阻塞，请注意！！！

## 新特性

### zookeeper

ZK 使用说明

解决 redis 锁的单点风险并对共享资源提供更强的安全保护；
解决redis和mysql生成序列的单点问题，调整序列组成规则，使其能够满足更高并发及更大业务量的需求。

### HibernateValidator

针对 HibernateValidator 进行了简单封装，支持快速失败。grus.hibernate.validator.enabled=true，详情见：Validator 模块

### Spring Redis 缓存框架

### WEB 的 Restful 接口日志打印

服务中的接口入参和出参，以及异常等可以利用框架直接打印日志了。Web日志打印 配合之前已有的 feign日志打印。可以减少应用在日志上的关注，更聚焦业务。

### Feign 支持多语言标识的传递（2022.x版本移除改特性）

后端系统通过HTTP请求的header来识别当前的语言环境，并通过feign的inteceptor向下游传递，feign多语言。

### PageHelper

grus 框架对 mybatis 分页提供统一的解决方案，提供 grus-boot-starter-pagehelper。传送门
